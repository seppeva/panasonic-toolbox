RP150 assignment Experimental

Assign cameras to the CAM buttons of an AW-RP150 by editing its connection file (Network.s15) and loading it back into the controller.

How it works

  1. Insert an SD card in the RP150. On the RP150 choose SYSTEM › CONNECT SETTING › DATA SAVE › YES.
  2. Put the SD card in this computer and open PRIVATE/MEIGROUP/PAVCN/SBG/SYSCAM/RP150/DATA/Network.s15 below.
  3. Fill in the assignment table: which camera IP goes to which CAM number. Take found cameras fills it from your camera list.
  4. Choose Save new Network.s15. The file is saved in Downloads › Panasonic Toolbox, together with a backup of the original.
  5. Copy the new file to the same folder on the SD card and replace the old one. Make sure it is called exactly Network.s15.
  6. Put the SD card back in the RP150 and choose SYSTEM › CONNECT SETTING › DATA LOAD, select the file and choose YES+NW so the network settings are loaded too.
  7. Press each CAM button and check that the right camera responds.

No SD card at hand? The RP150 can fill in the camera IP addresses itself: SYSTEM › AUTO IP SET › KEEP IP ADR keeps the cameras' current addresses and assigns them to free CAM numbers (CAM numbers set to NoAsign). RENEW IP ADR gives the cameras new addresses. You can't choose which camera gets which CAM number that way.

The layout of Network.s15 is not published by Panasonic. The app finds the table of IP addresses itself. If the RP150 refuses the file, nothing changes on the controller.

Network.s15

To set the connection type to LAN automatically, the app needs to know where it is stored: on the RP150 change the connection type of one CAM (CONNECT SETTING › CNNCT MD = LAN), save again with DATA SAVE and open that file as the second version.
