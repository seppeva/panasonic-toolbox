Save and restore the scene files of Panasonic PTZ cameras

An AW-RP120 or AW-RP150 cannot export a camera's shading. Panasonic Toolbox reads every setting of a scene, saves it to a file and puts it back on the same camera or another one.

Download Other systems and install help

Free for macOS 11 or later and Windows 10/11.

How it works

The app runs on your computer and talks to the cameras over the network, with the same commands an RP150 uses. No internet connection is needed.

  1. Put your computer in the cameras' IP range

    Give your computer a fixed address in the range of the cameras, for example 192.168.0.200 with subnet mask 255.255.255.0, and connect it to the same switch.

  2. Find the cameras

    Open Panasonic Toolbox and choose Scan network. Each PTZ shows up with its model, title and live scene. From the list you can also open a camera's live page or settings page, already logged in.

  3. Export

    Pick the cameras and either the live scene or scenes 1 to 4 (up to 8 on the AW-UE160). Each camera becomes a .pscene.json file in the folder you choose; several cameras go into one ZIP. Before the app switches scenes, it asks you to confirm.

  4. Import

    Open a file and choose for each scene which camera and which scene it goes to. The app saves the current settings as a backup first and reads everything back afterwards to check.

Or install from Terminal. This avoids the security warning when opening the app:

curl -fsSL https://seppeva.github.io/panasonic-toolbox/install.sh | bash
Opening the app for the first time
  1. Open the .dmg file and drag Panasonic Toolbox to Applications.
  2. The app is not registered with Apple yet, so the first time macOS says it cannot be opened. Click Done.
  3. Open System Settings, go to Privacy & Security and click Open Anyway next to Panasonic Toolbox at the bottom.
  4. When macOS asks whether the app may find devices on your local network, choose Allow. Without that permission the app cannot find any cameras.

  1. Run the installer. No administrator rights are needed.

  3. If Windows Firewall asks for access, allow private networks.
  4. Panasonic Toolbox then appears in the Start menu.

Features

Made for work on set: fast, predictable and without surprises in the picture.

Export without touching the picture
Reading the live scene changes nothing on air. For other scenes the app asks first, switches briefly and returns to the scene that was live.
Import with backup and check
See which values differ before you start. The destination scene is saved first and every value is read back afterwards.
Any file to any camera and scene
Choose per scene which camera and which scene it goes to, or send one look to several cameras, even across models. Settings a camera doesn't support are skipped and reported.
HTTP commands and scripts for Companion
Search every Panasonic camera command, from zoom and presets to tally and night mode, and copy a ready-made link for a GET request in Bitfocus Companion. Or bundle commands into a PowerShell or shell script that runs on several cameras at once.
Network setup
Find Panasonic cameras in any IP range, like Panasonic's Easy IP Setup, and give one or many of them a new IP address, subnet mask and gateway.
Shows
Save which scene file goes to which camera and scene, and put a whole show back on the cameras with one click.
Operator files
Take an operator's personal settings, such as preset speeds, pan/tilt, lens and tally preferences, from one camera to another, separate from the scenes.
Undo and redo
Step back through edits in the app as well as changes sent to the cameras.
Camera web pages in one click
Open a camera's live page or settings page in your browser from the camera list, logged in with the camera login you entered.
RP150 assignment
Assign the found cameras to CAM buttons, with connection type LAN or None, by editing the RP150's Network.s15 file from its SD card (experimental), with step-by-step instructions.
Works offline
Nothing goes through the internet and files stay on your computer. Only when you are online does the app check for a new version, and you can turn that off.
Cameras with a login
If User Auth is on, enter the user name and password once. You can choose to remember them on this computer.

Questions

The scan finds no cameras
  • Check that your computer is in the same range, for example 192.168.0.x with subnet mask 255.255.255.0.
  • Turn Wi-Fi off or give the wired connection priority.
  • Mac: in System Settings › Privacy & Security › Local Network, make sure Panasonic Toolbox is turned on.
  • Windows: allow Panasonic Toolbox on private networks in the firewall.
Does the picture change while exporting?

Not when you export the live scene only. To read other scenes the camera has to switch to them, so the app asks you to confirm first. Don't do that while a camera is on air.

Can I undo an import?

Yes. Before every import the app saves the current settings of the destination scene as a separate file. Import that file to go back.

Can the RP150 be used at the same time?

Yes, both control the same cameras and changes made in the app show up on the controller. Preferably don't operate the controller during an import.

Do I need to reinstall for an update?

Install the new version over the old one, for example with the same Terminal or PowerShell command. Your camera list and settings are kept.

Is this Panasonic software?

No. Panasonic Toolbox uses the publicly documented camera functions, but it is an independent tool.
